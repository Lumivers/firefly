# 7.1 图的表示与遍历

> 图由**顶点 (Vertex)** 与**边 (Edge)** 构成，是表达多对多复杂网络关系的通用模型。树、链表本质上均属于受限的特殊图结构。

## P0：核心考点

### 1.1 图的存储方式：邻接矩阵 vs 邻接表

如何将图中的点与边高效映射进内存，是所有图算法的前置基础：

| 维度 | 邻接矩阵 (Adjacency Matrix) | 邻接表 (Adjacency List) |
| :--- | :--- | :--- |
| **底层实现** | 二维数组 `vector<vector<int>> matrix[V][V]` | 向量的向量 `vector<vector<int>> adj[V]` |
| **空间复杂度** | **严格 $O(V^2)$**（与边的多少无关） | **$O(V + E)$**（按实际边数开辟） |
| **判断 $(u, v)$ 是否相连** | **$O(1)$**（直接读取 `matrix[u][v]`） | $O(\text{degree}(u))$（需遍历 $u$ 的邻接链表） |
| **查找节点 $u$ 的所有邻居** | $O(V)$（必须扫遍该行所有列） | **$O(\text{degree}(u))$**（仅包含真实邻居） |
| **增删边** | $O(1)$ | 增 $O(1)$，删 $O(\text{degree}(u))$ |
| **适用图类型** | **稠密图 (Dense Graph，边数 $E \approx V^2$)** | **稀疏图 (Sparse Graph，边数 $E \ll V^2$)** |
| **工业与算法选型** | 顶点极少（$V < 1000$）且边极多的场景 | **绝大多数场景的首选（95%+ 的业务均使用邻接表）** |

```cpp
// 1. 邻接矩阵表示
std::vector<std::vector<int>> matrix(n, std::vector<int>(n, 0));
matrix[u][v] = 1; // u 到 v 有边

// 2. 邻接表表示（工业最常用）
std::vector<std::vector<int>> adj(n);
adj[u].push_back(v); // u 的邻接列表中添加 v
```

### 1.2 图的遍历标准模板：BFS 与 DFS

> ⚠️ **核心戒律：必须使用 `visited` 集合防环！**
> 树因为没有环，从根向下单向延伸；但图**普遍存在环路**。若不记录已访问状态，遍历将陷入死循环导致程序崩溃。

#### 1. 广度优先搜索 (BFS) —— 队列实现
适合求解**无权图中的最短路径**或按层辐射扩散问题：
```cpp
#include <vector>
#include <queue>

void bfs(int start, const std::vector<std::vector<int>>& adj, std::vector<bool>& visited) {
    std::queue<int> q;
    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true; // 入队时立即标记访问，防止重复入队
                q.push(v);
            }
        }
    }
}
```

#### 2. 深度优先搜索 (DFS) —— 递归或显式栈
适合**路径搜索、连通分量遍历、拓扑排序与成环检测**：
```cpp
void dfs(int u, const std::vector<std::vector<int>>& adj, std::vector<bool>& visited) {
    visited[u] = true;
    for (int v : adj[u]) {
        if (!visited[v]) {
            dfs(v, adj, visited);
        }
    }
}
```

### 1.3 核心手撕：二分图判定 (LeetCode 785)

* **定义**：能否将图的所有顶点划分到两个互不相交的集合 $A$ 和 $B$ 中，使得图中的每条边的两个端点分别属于不同的集合（同集合内的点互不相连）。
* **染色法（双色标记）核心逻辑**：
  从任意未染色节点出发，将其涂为红色；随后通过 BFS/DFS 遍历其所有邻居节点，涂上相反的蓝色。在遍历过程中，**若发现邻居节点已经被涂上了与当前节点相同的颜色，则判定矛盾，该图不是二分图**。

```cpp
bool isBipartite(const std::vector<std::vector<int>>& graph) {
    int n = graph.size();
    std::vector<int> color(n, 0); // 0: 未访问, 1: 红色, -1: 蓝色

    for (int i = 0; i < n; ++i) {
        if (color[i] != 0) continue; // 已处理过的连通分量

        std::queue<int> q;
        q.push(i);
        color[i] = 1;

        while (!q.empty()) {
            int u = q.front();
            q.pop();

            for (int v : graph[u]) {
                if (color[v] == 0) {
                    color[v] = -color[u]; // 染相反颜色
                    q.push(v);
                } else if (color[v] == color[u]) {
                    return false; // 颜色冲突
                }
            }
        }
    }
    return true;
}
```

### 1.4 常见面试问答要点

* **Q：在有权图和无权图中，求两点间最短路径该如何选择遍历算法？**
  > **回答要点**：若是**无权图（或所有边的权值均相等）**，必须选用 **BFS**。因为 BFS 是逐层向外同心圆辐射的，首次访问到目标节点时的层数必然是全局最短步数，时间复杂度仅为 $O(V + E)$；若是**带权图**，BFS 无法保证全局权值最优，必须转向 **Dijkstra** 等专门的最短路径算法。

* **Q：为什么在图的 BFS 中，必须在“节点入队时”立即打上 `visited` 标记，而不是“出队时”才打？**
  > **回答要点**：若在出队时才打标记，当一个节点被多个同层的前驱节点同时指向时，该节点会被重复加入队列多次，导致队列规模急剧膨胀，在稠密图中会造成指数级的内存暴涨与重复运算。因此必须在 `push` 入队的瞬间立即锁定 `visited = true`。

## P1：经典算法模型

### 2.1 克隆图 (LeetCode 133)

* **问题**：深拷贝一个无向连通图（每个节点包含一个整数值和邻居指针列表）。
* **核心技巧**：使用哈希表 `unordered_map<Node*, Node*>` 建立**原始节点指针到全新深拷贝节点指针**的映射。在 BFS/DFS 遍历过程中，若邻居节点未被克隆过，则新建该节点并放入哈希表；若已存在则直接从哈希表中获取引用建立连接。

---

### 2.2 欧拉路径与欧拉回路判定（一笔画问题）

* **欧拉路径**：恰好经过图中每条边一次且仅一次的路径。
* **欧拉回路**：起点和终点重合的欧拉路径。
* **无向图判定条件**：
  - 必须是单一连通图（非孤立点）。
  - **欧拉回路**：所有顶点的度数均为**偶数**。
  - **欧拉路径**：恰好有 **0 个或 2 个**顶点的度数为**奇数**（若有 2 个，这两个顶点必然是起点与终点）。

## P2：工程实践：游戏网格图 (Grid Graph) 与视野模拟

在战棋、2D 像素与开放世界地图中，地图本质上是一个隐式图：
* **方向数组 (Direction Array)**：
  ```cpp
  constexpr int dx[4] = {0, 0, 1, -1};
  constexpr int dy[4] = {1, -1, 0, 0};
  ```
* **视野与迷雾探测 (Fog of War)**：
  玩家单位移动到 $(x, y)$ 时，以该点为起点发起限定最大步数（视野半径）的 BFS，动态染色可到达网格为“可见”，被障碍阻挡的格子则终止扩展。

## P3：基础原理与参考实现

### 3.1 基础图论术语速查

* **度 (Degree)**：无向图中与该点相连的边数；有向图细分为**入度 (In-Degree，指向自己的边数)** 与 **出度 (Out-Degree，从自己指出的边数)**。
* **连通图 vs 强连通图**：
  - **无向图**中任意两点间均存在路径，称为**连通图**。
  - **有向图**中任意两点 $u$ 和 $v$ 之间既存在 $u \to v$ 又存在 $v \to u$ 的路径，称为**强连通图 (Strongly Connected Graph)**。
