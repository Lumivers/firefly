# 6.4 堆与优先队列

> 堆是一种利用**一维连续数组**存储的**完全二叉树**，满足父子节点间的单调偏序关系。它能在 **$O(1)$** 极速获取全局最值，并在 **$O(\log n)$** 时间内完成动态元素的增删维护。

## P0：核心考点

### 1.1 完全二叉树的数组映射关系

二叉堆无需任何指针，完全依靠数组下标进行父子节点寻址（下标从 0 开始）：
* **父节点下标**：`parent(i) = (i - 1) / 2`
* **左孩子下标**：`left(i) = 2 * i + 1`
* **右孩子下标**：`right(i) = 2 * i + 2`
* **堆序性 (Heap Order)**：
  - **大顶堆 (Max-Heap)**：任意节点的值 $\ge$ 其子节点值（根节点为全局最大值）。
  - **小顶堆 (Min-Heap)**：任意节点的值 $\le$ 其子节点值（根节点为全局最小值）。

---

### 1.2 核心操作：上浮 (Sift-Up) 与 下沉 (Sift-Down)

#### 1. 上浮 (Sift-Up) —— 对应 `push` 操作
新元素直接追加在数组末尾。若新元素大于其父节点，破坏了大顶堆性质，需**不断与父节点交换位置**，直到满足堆序性或到达根部。
* 时间复杂度：$O(\log n)$。

#### 2. 下沉 (Sift-Down) —— 对应 `pop` 堆顶操作
将数组末尾的最后一个元素移动到堆顶覆盖原最大值，然后执行下沉：**在左右孩子中找出较大者，若较大孩子大于当前节点，则与该孩子交换**，层层下沉直至满足堆序性或成为叶子节点。
* 时间复杂度：$O(\log n)$。

```cpp
// 大顶堆核心下沉算法
void sift_down(std::vector<int>& heap, int n, int i) {
    while (2 * i + 1 < n) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int best = i;

        if (heap[left] > heap[best]) best = left;
        if (right < n && heap[right] > heap[best]) best = right;

        if (best == i) break; // 已满足堆序性
        std::swap(heap[i], heap[best]);
        i = best; // 继续向下追踪
    }
}
```

### 1.3 核心证明：为什么原地建堆是 $O(n)$ 而非 $O(n \log n)$？

这是技术面试中极其经典的理论推导题：从一个无序数组原地构建堆，如果对每个元素执行 `push`（上浮），复杂度为 $O(n \log n)$；但若采用**自底向上下沉法 (Heapify)**，复杂度为严格 **$O(n)$**。

* **建堆过程**：从最后一个非叶子节点 `(n - 2) / 2` 开始，逆向逐个往前执行 `sift_down`。
* **数学推导**：
  设树的高度为 $h = \log_2 n$。
  - 第 $k$ 层（根为第 0 层）包含至多 $2^k$ 个节点，该层节点最大下沉距离为 $h - k$。
  - 全局总交换次数为各层节点数乘以对应下沉距离的累加和：
    $$S = \sum_{k=0}^{h-1} 2^k (h - k) = 1 \cdot h + 2(h - 1) + 4(h - 2) + \dots + 2^{h-1} \cdot 1$$
  - 两边同乘以 2，错位相减得：
    $$2S - S = h + 2 + 4 + 8 + \dots + 2^h - (h + 1) = 2^{h+1} - h - 2$$
  - 由于 $2^h \approx n$，代入得：
    $$S \approx 2n - \log_2 n - 2 = \mathbf{O(n)}$$
* **直观理解**：下沉法中，占据绝大多数的底层节点（占节点总数一半的叶子）下沉距离为 0；而距离较长的高层节点数量呈指数级递减，加权和收敛为线性 $O(n)$。

### 1.4 核心手撕：数据流的中位数 (LeetCode 295)

* **问题**：设计一个数据结构，动态接收数据流并实时以 $O(1)$ 时间返回中位数。
* **双堆对顶模型**：
  - `max_heap`：维护较小的一半数字（大顶堆）。
  - `min_heap`：维护较大的一半数字（小顶堆）。
  - **平衡约束**：保证 `max_heap.size() == min_heap.size()`，或 `max_heap.size() == min_heap.size() + 1`。
  - **中位数计算**：若总数为奇数，直接返回 `max_heap.top()`；若为偶数，返回两堆堆顶平均值。

```cpp
#include <queue>

class MedianFinder {
    std::priority_queue<int> _max_heap; // 存较小一半
    std::priority_queue<int, std::vector<int>, std::greater<int>> _min_heap; // 存较大一半

public:
    void addNum(int num) {
        if (_max_heap.empty() || num <= _max_heap.top()) {
            _max_heap.push(num);
        } else {
            _min_heap.push(num);
        }

        // 平衡两堆数量
        if (_max_heap.size() > _min_heap.size() + 1) {
            _min_heap.push(_max_heap.top());
            _max_heap.pop();
        } else if (_min_heap.size() > _max_heap.size()) {
            _max_heap.push(_min_heap.top());
            _min_heap.pop();
        }
    }

    double findMedian() {
        if (_max_heap.size() > _min_heap.size()) {
            return _max_heap.top();
        }
        return (_max_heap.top() + _min_heap.top()) / 2.0;
    }
};
```

### 1.5 常见面试问答要点

* **Q：在数据流中寻找前 K 个最大值，该选大顶堆还是小顶堆？**
  > **回答要点**：**必须选用大小为 K 的小顶堆**。遍历数据流时，如果新元素大于堆顶，则弹出堆顶并压入新元素。遍历结束后，堆内保留的 $K$ 个元素即为全局最大的 $K$ 个，而堆顶恰好是第 $K$ 大元素。若误选大顶堆，则必须将全部 $N$ 个元素全量入堆，空间退化为 $O(N)$。

* **Q：`std::priority_queue` 为什么不支持修改已存元素的优先级或删除指定元素？**
  > **回答要点**：标准库中的二叉堆是一个连续数组，在没有维护“外部对象到数组下标反向映射”的情况下，寻找某个指定元素需要 $O(n)$ 全表扫描。若需要高效动态调整优先级，必须使用专门的**索引堆 (Indexed Priority Queue)**。

## P1：经典算法模型

### 2.1 原地堆排序 (Heap Sort) 手写实现

堆排序是时间复杂度稳定为 $O(n \log n)$ 且额外空间复杂度为严格 **$O(1)$** 的经典比较类排序：
1. **构建大顶堆**：自底向上执行 `heapify`，将原始数组原地构造成大顶堆。
2. **首尾交换与调整**：将堆顶元素（全局最大）与当前有效区间的末尾元素交换，有效区间长度减 1，对新堆顶执行 `sift_down`。循环直到区间为空。

```cpp
void heapSort(std::vector<int>& arr) {
    int n = arr.size();
    // 1. 原地建堆 O(n)
    for (int i = (n - 2) / 2; i >= 0; --i) {
        sift_down(arr, n, i);
    }
    // 2. 依次将堆顶换至末尾 O(n log n)
    for (int i = n - 1; i > 0; --i) {
        std::swap(arr[0], arr[i]);
        sift_down(arr, i, 0); // 在 [0, i) 区间内重新下沉
    }
}
```

### 2.2 索引堆 (Indexed Heap) 核心概念

* **痛点**：普通优先队列无法在 $O(\log n)$ 内根据元素 ID 更新其权值（如 Dijkstra 最短路算法中更新节点的距离）。
* **解决方案**：引入 `index_to_pos` 与 `pos_to_index` 两个辅助映射数组，通过在元素交换时同步更新反向索引，实现根据外部 ID 以 **$O(\log n)$** 完成任意节点的 `change_priority` 和 `erase`。

## P2：工程实践与业务场景

### 3.1 游戏引擎定时器管理系统 (Timer Manager)

游戏服务端的定时任务调度：
* 每个定时器记录绝对触发时间戳 `timestamp`。
* 放入基于时间戳排序的小顶堆中，堆顶始终是**最早即将到期**的任务。
* 每帧只需检查 `堆顶.timestamp <= 当前时间`：若到期则弹出执行回调，否则立即结束检查，无需遍历所有未到期定时器。

### 3.1 全操作复杂度速查总表

| 操作接口 | 时间复杂度 | 空间复杂度 | 对应行为 |
| :--- | :--- | :--- | :--- |
| `top()` | **$O(1)$** | $O(1)$ | 直接读取数组 `arr[0]` |
| `push()` | **$O(\log n)$** | $O(1)$ | 追加末尾并上浮 |
| `pop()` | **$O(\log n)$** | $O(1)$ | 尾元素覆盖头并下沉 |

### 3.2 手写通用大顶堆完整实现

```cpp
#include <vector>
#include <stdexcept>
#include <utility>

template <typename T>
class MaxHeap {
    std::vector<T> _data;

    void _sift_up(int i) {
        while (i > 0) {
            int p = (i - 1) / 2;
            if (_data[i] <= _data[p]) break;
            std::swap(_data[i], _data[p]);
            i = p;
        }
    }

    void _sift_down(int i) {
        int n = _data.size();
        while (2 * i + 1 < n) {
            int left = 2 * i + 1;
            int right = 2 * i + 2;
            int best = i;

            if (_data[left] > _data[best]) best = left;
            if (right < n && _data[right] > _data[best]) best = right;

            if (best == i) break;
            std::swap(_data[i], _data[best]);
            i = best;
        }
    }

public:
    MaxHeap() = default;

    void push(const T& val) {
        _data.push_back(val);
        _sift_up(_data.size() - 1);
    }

    T pop() {
        if (_data.empty()) throw std::underflow_error("Heap is empty");
        T max_val = _data[0];
        _data[0] = _data.back();
        _data.pop_back();
        if (!_data.empty()) _sift_down(0);
        return max_val;
    }

    const T& top() const {
        if (_data.empty()) throw std::underflow_error("Heap is empty");
        return _data[0];
    }

    bool empty() const { return _data.empty(); }
    size_t size() const { return _data.size(); }
};
```
</details>
