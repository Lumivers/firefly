## P0：核心考点

### 1.1 KMP 算法核心原理：主串指针绝不回溯

朴素暴力匹配在失配时，主串指针必须回退，导致最坏时间复杂度高达 $O(n \cdot m)$。
**KMP 的核心突破**：**主串指针 $i$ 始终单向向前移动，绝不回退**；当在模式串位置 $j$ 发生失配时，利用已经成功匹配过的已知前缀信息，将模式串向右“滑行”，令模式串指针跳转到 `next[j - 1]` 处继续比对。

#### `next` 数组（前缀表）的物理意义
`next[i]` 存储的是：**模式串子串 `pattern[0..i]` 中，最长相等前后缀 (Longest Common Prefix and Suffix) 的长度**。
* 例如字符串 `"aabaa"`：
  - 前缀：`"a"`, `"aa"`, `"aab"`, `"aaba"`
  - 后缀：`"a"`, `"aa"`, `"baa"`, `"abaa"`
  - 最长公共前后缀为 `"aa"`，长度为 2。

### 1.2 核心手撕：KMP 算法标准实现

```cpp
#include <vector>
#include <string>

// 1. 构建前缀表 next 数组：时间 O(m)
std::vector<int> buildNext(const std::string& p) {
    int m = p.size();
    std::vector<int> next(m, 0);
    int j = 0; // 当前最长公共前后缀长度

    for (int i = 1; i < m; ++i) {
        while (j > 0 && p[i] != p[j]) {
            j = next[j - 1]; // 失配时向前回退
        }
        if (p[i] == p[j]) {
            ++j;
        }
        next[i] = j;
    }
    return next;
}

// 2. KMP 匹配主函数：时间 O(n)
int kmpSearch(const std::string& s, const std::string& p) {
    if (p.empty()) return 0;
    int n = s.size(), m = p.size();
    std::vector<int> next = buildNext(p);
    int j = 0; // 模式串匹配到的位置

    for (int i = 0; i < n; ++i) {
        while (j > 0 && s[i] != p[j]) {
            j = next[j - 1]; // 模式串指针跳转，主串指针 i 保持不动！
        }
        if (s[i] == p[j]) {
            ++j;
        }
        if (j == m) {
            return i - m + 1; // 首次完全匹配的起始下标
        }
    }
    return -1; // 未匹配
}
```
* **时空复杂度**：时间复杂度严格保证为 **$O(n + m)$**，额外空间复杂度为 $O(m)$。

### 1.3 字符串多项式滚动哈希 (Rabin-Karp)

将字符串视作大进制数（如 Base = 131），通过多项式哈希将任意子串映射为一个无符号 64 位整数（利用 `uint64_t` 自然溢出等价于模 $2^{64}$）：
$$\text{hash}(s[0..k]) = s[0] \cdot B^k + s[1] \cdot B^{k-1} + \dots + s[k]$$
* **$O(1)$ 提取子串哈希**：预处理前缀哈希数组 `h` 与进制乘方数组 `p`，则子串 $s[l..r]$ 的哈希值为：
  $$\text{hash}(s[l..r]) = h[r] - h[l - 1] \times p[r - l + 1]$$
* **应用**：可在 $O(1)$ 时间内快速判断两个任意长度的子串是否相同，用于重复子串检测与长文本查重。

### 1.4 常见面试问答要点

* **Q：KMP 算法的 `next` 数组构建与主串匹配过程为什么逻辑几乎一模一样？**
  > **回答要点**：因为 `next` 数组的推导本质上是**模式串与它自身进行“自我前缀匹配”的过程**。主串匹配是主串字符 `s[i]` 与模式串字符 `p[j]` 比较，而构建前缀表是模式串后缀字符 `p[i]` 与模式串前缀字符 `p[j]` 比较，两者的失配回溯机制在数学结构上完全一致。

## P1：进阶多模式串与回文模型

### 2.1 AC 自动机 (Aho-Corasick Automaton)

* **痛点**：若有 1000 个敏感词，KMP 必须对每个敏感词独立扫描一遍文本，总时间为 $1000 \times O(n)$。
* **核心架构**：**Trie 树 + KMP 失败指针 (Fail Pointer)**。
  - 将所有敏感词构建为一棵 Trie 树。
  - 借助 BFS 为树中每个节点计算 `fail` 指针（指向当前前缀在树中所能匹配的**最长后缀节点**）。
  - **效果**：在单次 $O(n)$ 线性扫描文本的过程中，同时并发匹配所有 1000 个模式串，构成了工业级敏感词审查的标准框架。

---

### 2.2 Manacher 算法 ($O(n)$ 最长回文子串)

常规中心扩展法寻找最长回文子串为 $O(n^2)$。
**Manacher (马拉车) 算法**：
1. **统一奇偶长度**：在每个字符间插入分隔符 `#`，将所有回文转化为奇数长度。
2. **利用回文对称性**：维护当前已探明的全局最右回文边界 $R$ 及其对称中心 $C$。对于当前考察点 $i$，若 $i < R$，直接利用其关于 $C$ 的对称点 $j = 2C - i$ 的已知回文半径进行快速初始化，避免重复字符比对，将复杂度压降至严格 **$O(n)$**。

## P2：工程实践与业务场景

1. **游戏敏感词快速拦截过滤**：玩家聊天发送文本时，利用 AC 自动机单次流式扫过字符串，命中词汇立即被就地重写替换为 `***`。
2. **游戏资产包差量更新 (Delta Update)**：利用 Rabin-Karp 滚动哈希将大二进制数据包按固定窗口切片比对指纹，快速找出发生变动的数据块，仅下载差异补丁。
