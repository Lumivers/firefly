# 第一章 排序算法与分治范式

> 排序是将一组无序数据按特定规则重排为有序序列的过程。它不仅是算法领域的基石，也是经典**分治法 (Divide and Conquer)** 与现代硬件**缓存局部性优化**的最佳范例。

## P0：核心考点

### 1.1 排序算法全景对比总表

这是算法与基础面试中考察最密集的核心表格：

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 最好时间复杂度 | 额外空间复杂度 | 稳定性 | 核心算法思想 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **冒泡排序** | $O(n^2)$ | $O(n^2)$ | $O(n)$ | $O(1)$ | **稳定** | 蛮力枚举，相邻交换 |
| **选择排序** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **不稳定** | 蛮力选择区间极值 |
| **插入排序** | $O(n^2)$ | $O(n^2)$ | **$O(n)$** | $O(1)$ | **稳定** | 减治法（减 1），近乎有序时极快 |
| **快速排序** | **$O(n \log n)$** | $O(n^2)$ | $O(n \log n)$ | **$O(\log n)$ 栈** | **不稳定** | **分治法**（以 Pivot 划分子区间） |
| **归并排序** | **$O(n \log n)$** | **$O(n \log n)$** | **$O(n \log n)$** | **$O(n)$** | **稳定** | **分治法**（先二分递归再双路合并） |
| **堆排序** | **$O(n \log n)$** | **$O(n \log n)$** | $O(n \log n)$ | **$O(1)$ 原地** | **不稳定** | 树形堆序性，原地选择最值 |
| **计数排序** | $O(n + k)$ | $O(n + k)$ | $O(n + k)$ | $O(k)$ | **稳定** | 桶映射，非比较排序 |
| **基数排序** | $O(d(n + k))$ | $O(d(n + k))$ | $O(d(n + k))$ | $O(n + k)$ | **稳定** | 多关键字按位分配收集 |

> 💡 **稳定性定义**：若序列中存在两个相等的元素 $A$ 和 $B$，排序前 $A$ 排在 $B$ 前面，排序后 $A$ **依然必须排在 $B$ 前面**，则称该排序是**稳定的**。在涉及“多关键字多重排序（如先按成绩排序，相同再按年龄排序）”时，稳定性是绝对刚需。

### 1.2 核心手撕 1：快速排序 (QuickSort)

快速排序基于分治法：挑选一个基准值 (Pivot)，将数组划分为“小于 Pivot”与“大于 Pivot”两部分，随后对左右两半递归求解。

#### 1. 双指针单向移动（双路划分经典实现）
```cpp
#include <vector>
#include <algorithm>

int partition(std::vector<int>& arr, int low, int high) {
    // 优化：三数取中选取基准并换至末尾，避免已排序数组导致 O(n^2) 退化
    int mid = low + (high - low) / 2;
    if (arr[mid] < arr[low]) std::swap(arr[low], arr[mid]);
    if (arr[high] < arr[low]) std::swap(arr[low], arr[high]);
    if (arr[high] < arr[mid]) std::swap(arr[mid], arr[high]);
    std::swap(arr[mid], arr[high]);

    int pivot = arr[high];
    int i = low;

    for (int j = low; j < high; ++j) {
        if (arr[j] < pivot) {
            std::swap(arr[i], arr[j]);
            ++i;
        }
    }
    std::swap(arr[i], arr[high]);
    return i; // 返回基准值最终下标
}

void quickSort(std::vector<int>& arr, int low, int high) {
    if (low < high) {
        int p = partition(arr, low, high);
        quickSort(arr, low, p - 1);
        quickSort(arr, p + 1, high);
    }
}
```

### 1.3 核心手撕 2：归并排序 (MergeSort)

归并排序严格遵循分治三部曲：
1. **分 (Divide)**：找到中点二分切分数组。
2. **治 (Conquer)**：递归对左右子数组进行归并排序。
3. **合 (Combine)**：利用双指针将两个已排好序的有序子数组合并为一个有序数组。

```cpp
#include <vector>

void merge(std::vector<int>& arr, int l, int m, int r, std::vector<int>& temp) {
    int i = l, j = m + 1, k = l;

    while (i <= m && j <= r) {
        if (arr[i] <= arr[j]) { // <= 保证算法稳定性
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }
    while (i <= m) temp[k++] = arr[i++];
    while (j <= r) temp[k++] = arr[j++];

    for (int p = l; p <= r; ++p) arr[p] = temp[p];
}

void mergeSort(std::vector<int>& arr, int l, int r, std::vector<int>& temp) {
    if (l >= r) return;
    int mid = l + (r - l) / 2;
    mergeSort(arr, l, mid, temp);
    mergeSort(arr, mid + 1, r, temp);
    merge(arr, l, mid, r, temp);
}
```

### 1.4 `std::sort` 底层内省排序 (Introsort) 机制

为什么 C++ 标准库中的 `std::sort` 不直接用纯快排？
* **快排致命弱点**：若每次划分极度不平衡（如退化为 $1$ 与 $n-1$），时间复杂度会退化为 $O(n^2)$，递归栈深度达到 $O(n)$。
* **Introsort 混合三大算法**：
  1. **主干使用快速排序**：平均情况下效率最高。
  2. **深度阈值切换堆排序**：当递归深度超过 $2 \log_2 n$ 时，判定快排可能已退化，**立即切换为堆排序 (HeapSort)**，强制将最坏时间复杂度锁定在 $O(n \log n)$。
  3. **微小区间切换插入排序**：当切分后的子数组长度小于设定阈值（通常为 16）时，停止递归，直接转用**插入排序 (InsertionSort)**（因为小数据量下插入排序常数极低且无递归开销）。

### 1.5 常见面试问答要点

* **Q：为什么快速排序不稳定？举个例子？**
  > **回答要点**：快排在划分阶段会发生**跨越式的大步长交换**。例如序列 `[5a, 5b, 2]`，基准选 2。在划分过程中，$5a$ 会直接与 2 进行位置互换，数组变为 `[2, 5b, 5a]`，原本在前的 $5a$ 跑到了 $5b$ 的后面，破坏了相对先后次序。

* **Q：为什么链表排序首选归并排序而非快速排序？**
  > **回答要点**：快排强依赖随机访问（数组下标访问）与双向双指针划分；链表不支持 $O(1)$ 随机定位，且指针回溯困难。而归并排序仅需**快慢指针找中点截断**，以及双指针线性串接两个链表节点，合并过程完全是原地修改指针（无需额外开辟 $O(n)$ 辅助数组），因此链表排序是归并排序的最佳主场。

## P1：算法设计范式与经典模型

### 2.1 分治法 (Divide and Conquer) 范式与主定理

算法课的核心理论之一：将规模为 $n$ 的原问题分解为 $a$ 个规模为 $n/b$ 的相互独立的子问题：
$$T(n) = a T\left(\frac{n}{b}\right) + f(n)$$
其中 $f(n)$ 为划分与合并子问题所需的额外工作量。

#### 主定理 (Master Theorem) 判定规则
比较 $f(n)$ 与临界多项式 $n^{\log_b a}$ 的渐进增长速度：
1. **若 $f(n) < n^{\log_b a}$**：递归树叶子节点耗时占主导，$T(n) = \Theta(n^{\log_b a})$。
2. **若 $f(n) = \Theta(n^{\log_b a} \log^k n)$**：每层耗时均衡，$T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$。
   * *典型例*：归并排序 $a=2, b=2, f(n)=O(n)$，此时 $n^{\log_2 2} = n^1$，对应第 2 种情况 ($k=0$)，故 $T(n) = O(n \log n)$。
3. **若 $f(n) > n^{\log_b a}$**：顶层划分与合并占主导，$T(n) = \Theta(f(n))$。

### 2.2 快速选择算法 (QuickSelect，LeetCode 215)

* **目标**：在未排序数组中以**均摊 $O(n)$** 时间复杂度寻找第 $K$ 大（或第 $K$ 小）元素。
* **分治思想**：借助快速排序的 `partition` 过程。每次划分后，基准点被固定在全局最终位置 $P$：
  - 若 $P == K$：说明已精准命中目标，直接返回 `arr[P]`！
  - 若 $K < P$：目标必定在左半段，**仅递归左半段**。
  - 若 $K > P$：目标必定在右半段，**仅递归右半段**。
* **复杂度分析**：因为每次只进入一个分支（单侧递归），总工作量为 $n + n/2 + n/4 + \dots \approx 2n = \mathbf{O(n)}$。

### 2.3 荷兰国旗问题（三路划分，LeetCode 75）

当数组中存在大量重复元素时，传统双路快排会导致递归树极不平衡。**三路快排 (Three-way Partition)** 将区间一分为三：`< Pivot`、`== Pivot`、`> Pivot`。

```cpp
void sortColors(std::vector<int>& nums) {
    int zero = 0;              // [0, zero) 严格为 0
    int two = nums.size() - 1; // (two, end] 严格为 2
    int i = 0;                 // [zero, i) 严格为 1

    while (i <= two) {
        if (nums[i] == 0) {
            std::swap(nums[i++], nums[zero++]);
        } else if (nums[i] == 2) {
            std::swap(nums[i], nums[two--]); // 注意：换回来的元素未检查，i 不递增
        } else {
            ++i;
        }
    }
}
```

## P2：工程实践与性能优化

### 3.1 为什么实际运行中快排远快于堆排？（Cache 友好性）

虽然堆排序与快速排序的时间复杂度均为 $O(n \log n)$，且堆排最坏情况更稳，但工业界绝对优先选择快排或其变体：
* **快速排序（顺序局部性强）**：双指针连续线性向中间扫描，元素访问在物理内存上是连续紧凑的，CPU Cache Line 命中率极高。
* **堆排序（缓存极其不友好）**：父节点在 $i$，其子节点在 $2i+1$ 和 $2i+2$。每一次下沉和比较，内存访问跨度呈指数级跳跃，在大型数组下几乎每次比较都是一次昂贵的 Cache Miss。

---

### 3.2 游戏渲染排序：画家算法 (Painter's Algorithm)

在 3D 图形学中，对于**不透明物体**，GPU 依靠深度缓冲 (Z-Buffer) 即可自动剔除被遮挡片段；但对于**半透明物体（如水面、火焰、烟雾、毛玻璃）**，Alpha 混合必须严格遵守**从后向前 (Back-to-Front)** 的顺序绘制，否则会发生透光渲染错误。
* 渲染引擎每一帧会对所有待渲染的半透明材质，根据其到摄像机的距离深度进行**一次快速排序**，再提交给 GPU 绘制管线。
