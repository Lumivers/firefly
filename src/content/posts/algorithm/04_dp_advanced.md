# 第四章 动态规划进阶：区间、状压与树形

> 当问题的状态不再是简单的一维线性前缀，而是**子区间的合并**、**组合集合的覆盖**或**树形结构的依赖汇聚**时，动态规划跃升为高维模型。虽然状态空间定义发生变化，但“最优子结构”与“无后效性”的核心准则始终如一。

## P0：核心考点

### 1.1 区间 DP：长度由小到大的枚举范式

* **适用场景**：大区间的状态由若干较小子区间合并而来（如石子合并、表达式加括号、戳气球）。
* **核心循环顺序规则**：
  **外层必须枚举区间长度 `len`，内层枚举左端点 `i`，最内层枚举分割点 `k`**。
  - **原因**：大区间的计算强依赖于短区间的计算结果。若直接按普通的行优先或列优先循环，计算当前区间时短区间尚未就绪，破坏无后效性。

#### 标准循环骨架
```cpp
for (int len = 2; len <= n; ++len) { // 1. 枚举区间长度
    for (int i = 0; i <= n - len; ++i) { // 2. 枚举区间起点
        int j = i + len - 1; // 区间终点
        for (int k = i; k < j; ++k) { // 3. 枚举分割点
            dp[i][j] = std::max(dp[i][j], dp[i][k] + dp[k + 1][j] + cost(i, k, j));
        }
    }
}
```

---

### 1.2 状态压缩 DP：二进制位掩码表示

* **适用场景**：问题规模较小（通常 $n \le 20$），某个集合或元素的选取状态有且仅有“选/未选”两种可能。
* **位掩码 (Bitmask) 表示法**：
  使用一个非负整数的二进制位来压缩表示子集状态：
  - 第 $i$ 位为 `1`：表示第 $i$ 个元素已被选取；
  - 第 $i$ 位为 `0`：表示第 $i$ 个元素未被选取。
  - 总状态数量恰好为 $2^n$（对应整数区间 $[0, 2^n - 1]$）。

#### 常见位运算操作
* 检查第 $i$ 位是否为 1：`(state >> i) & 1`
* 将第 $i$ 位置为 1（加入集合）：`state | (1 << i)`
* 将第 $i$ 位置为 0（移出集合）：`state & ~(1 << i)`

---

### 1.3 树形 DP：自底向上的后序遍历

* **适用场景**：状态依赖定义在树的层级结构上，父节点的最优解依赖于所有子树的最优解（如打家劫舍 III、树的最大独立集）。
* **核心运行机制**：
  必须基于**后序遍历 (Post-order)**。每个节点递归向子树索取信息，收集齐所有子节点的状态后，在当前节点进行状态转移合并，最后向上返回。

#### 典型手撕：打家劫舍 III (LeetCode 337)
每个节点返回一个包含两个元素的二元组：`[不偷当前节点的最大收益, 偷当前节点的最大收益]`。

```cpp
#include <utility>
#include <algorithm>

// 返回 pair<int, int>: first 为不选当前节点，second 为选取当前节点
std::pair<int, int> dfs(TreeNode* node) {
    if (!node) return {0, 0};

    auto [left_unrob, left_rob] = dfs(node->left);
    auto [right_unrob, right_rob] = dfs(node->right);

    // 1. 若偷当前节点：左右子节点绝对不能偷
    int rob = node->val + left_unrob + right_unrob;

    // 2. 若不偷当前节点：左右子节点可以偷也可以不偷，取各自较大者
    int unrob = std::max(left_unrob, left_rob) + std::max(right_unrob, right_rob);

    return {unrob, rob};
}

int rob(TreeNode* root) {
    auto [unrob, rob] = dfs(root);
    return std::max(unrob, rob);
}
```

### 1.4 常见面试问答要点

* **Q：为什么很多状压 DP 的数据规模 $N$ 往往限制在 20 以内？**
  > **回答要点**：状压 DP 将子集组合状态编码为二进制数，状态总数呈指数级增长（$2^N$）。当 $N = 20$ 时，$2^{20} \approx 10^6$，状态转移耗时约在 $10^7 \sim 10^8$ 次运算之间，恰好处于现代计算机 1 秒可执行的算力极限边缘（$10^8$ 次操作）。一旦 $N > 25$，$2^{25} \approx 3.3 \times 10^7$，时间与空间均会发生组合爆炸导致超时或内存溢出。

## P1：经典进阶模型与优化

### 2.1 戳气球 (LeetCode 312)：逆向思维的区间 DP

* **正向思考的困境**：若按戳破气球的正向顺序，每次戳破一个气球后，原本不相邻的两个气球会变为相邻，导致子问题之间相互耦合产生“后效性”。
* **逆向反转思维**：
  定义 `dp[i][j]` 为戳破开区间 $(i, j)$ 内所有气球的最大金币数。**假设气球 $k$ 是该区间内【最后一个被戳破】的气球**：
  - 既然 $k$ 是最后一个戳破的，那么在戳破 $k$ 的那一瞬间，开区间 $(i, j)$ 内的其他气球已经全部被戳破了！
  - 此时与 $k$ 相邻的气球必然就是边界 $i$ 和 $j$。
  - 状态转移方程：
    $$dp[i][j] = \max_{i < k < j} (dp[i][k] + dp[k][j] + \text{nums}[i] \times \text{nums}[k] \times \text{nums}[j])$$
  - 彻底消除了后效性，转化为标准区间 DP。

---

### 2.2 单调队列优化 DP

在形如 $dp[i] = \max_{i - k \le j < i} (dp[j] + \text{cost}(j)) + \text{val}[i]$ 的状态转移中，朴素遍历历史状态 $j$ 需耗时 $O(k)$，总时间复杂度为 $O(n \cdot k)$。
* **单调队列优化**：利用双端队列维护滑动窗口内的最大值，将内层线性扫描降为 **$O(1)$** 均摊，总时间复杂度优化至 **$O(n)$**。

## P2：工程实践与业务场景

1. **道具最优融合路线规划**：合成高阶装备时，各低阶材料按区间两两合并产生额外附加损耗，利用区间 DP 计算全局最小消耗。
2. **多依赖天赋点解锁评估**：玩家在天赋树中有多种分支选择，不同分支提供互斥属性加成，使用状压 DP 遍历计算限定技能点数下的最强战力搭配。

### 3.2 旅行商问题 (TSP) 状压 DP 参考源码

<details>
<summary>👉 查看使用位掩码动态规划求解 TSP 最短环路的 C++ 源码</summary>

```cpp
#include <vector>
#include <algorithm>

const int INF = 1e9;

// dist[n][n] 为各城市两两距离矩阵
int tsp(int n, const std::vector<std::vector<int>>& dist) {
    // dp[mask][u]: 已经访问过的城市集合为 mask，当前停留在城市 u 的最短距离
    std::vector<std::vector<int>> dp(1 << n, std::vector<int>(n, INF));

    // 初始状态：从城市 0 出发
    dp[1][0] = 0;

    for (int mask = 1; mask < (1 << n); ++mask) {
        for (int u = 0; u < n; ++u) {
            if (!(mask & (1 << u)) || dp[mask][u] == INF) continue;

            // 尝试下一个未访问的城市 v
            for (int v = 0; v < n; ++v) {
                if (!(mask & (1 << v))) {
                    int next_mask = mask | (1 << v);
                    dp[next_mask][v] = std::min(dp[next_mask][v], dp[mask][u] + dist[u][v]);
                }
            }
        }
    }

    // 回到起点 0 闭合回路
    int ans = INF;
    int final_mask = (1 << n) - 1;
    for (int u = 1; u < n; ++u) {
        ans = std::min(ans, dp[final_mask][u] + dist[u][0]);
    }
    return ans;
}
```
</details>
