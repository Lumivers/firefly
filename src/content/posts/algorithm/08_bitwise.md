# 第八章 位运算与状态压缩

> 位运算直接在 CPU 寄存器的二进制级别操作数据。它不仅能将 32 或 64 个布尔状态紧凑压缩进单个整数中，还能通过单指令周期的高并发位逻辑，消除复杂的条件分支跳转。

## P0：核心考点

### 1.1 三大核心位运算技巧

#### 1. `x & (x - 1)`：消去二进制中最右侧的 1
* **原理**：$x - 1$ 会将 $x$ 最低位的 1 变为 0，并将其右侧所有的 0 反转为 1；两者按位与后，恰好仅消去该最低位的 1。
* **高频应用**：
  - **统计二进制中 1 的个数 (LC 191)**：执行 `x = x & (x - 1)` 的次数恰好等于 1 的总数。
  - **判断是否为 2 的幂次方 (LC 231)**：若 $x > 0$ 且 `(x & (x - 1)) == 0`，则 $x$ 是 2 的幂。

#### 2. `x & (-x)`：仅保留二进制中最右侧的 1 (`lowbit`)
* **原理**：利用补码性质，$-x = \sim x + 1$。
* **高频应用**：树状数组的核心索引计算，快速定位最低有效位。

#### 3. 异或运算 (`^`)：无进位加法与成对消除
* **特性**：
  - $x \oplus x = 0$（自反性）
  - $x \oplus 0 = x$
  - 交换律与结合律：$a \oplus b \oplus a = b$
* **高频应用**：寻找成对出现中唯一落单的数 (LC 136)。

---

### 1.2 第 $k$ 位掩码通用操作规范

设最低位为第 0 位：
* **查询第 $k$ 位是否为 1**：`(x >> k) & 1`（或 `(x & (1 << k)) != 0`）
* **将第 $k$ 位置为 1**：`x |= (1 << k)`
* **将第 $k$ 位置为 0**：`x &= ~(1 << k)`
* **将第 $k$ 位翻转 (0变1, 1变0)**：`x ^= (1 << k)`

### 1.3 核心手撕：只出现一次的数字 (LeetCode 136)

> 给定一个非空整数数组，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。要求 $O(n)$ 时间与 $O(1)$ 空间。

```cpp
int singleNumber(const std::vector<int>& nums) {
    int ans = 0;
    for (int x : nums) {
        ans ^= x; // 所有成对出现的数异或后互相抵消为 0，最终留下的即为落单数
    }
    return ans;
}
```

### 1.4 常见面试问答要点

* **Q：位运算操作符的优先级陷阱是什么？**
  > **回答要点**：C/C++ 中**位运算符（如 `&`, `|`, `^`）的优先级普遍低于关系比较运算符（`==`, `!=`, `<`, `>`）**。例如表达式 `if (x & 1 == 0)` 实际上会被编译器解析为 `if (x & (1 == 0))`，导致逻辑完全错误。因此在书写位运算表达式时，**必须对位操作部分显式加外层括号**，如 `if ((x & 1) == 0)`。

## P1：集合枚举与高级技巧

### 2.1 全子集二进制枚举

对于大小为 $n$ 的集合，其所有 $2^n$ 个可能子集可由整数 `0` 到 `(1 << n) - 1` 一对一对应：

```cpp
for (int mask = 0; mask < (1 << n); ++mask) {
    for (int i = 0; i < n; ++i) {
        if (mask & (1 << i)) {
            // 当前子集包含元素 i
        }
    }
}
```

---

### 2.2 颠倒无符号二进制位 (LeetCode 190)

* **分治交换思想**：类比归并，先按 16 位高低交换，再按 8 位、4 位、2 位、1 位逐级分组交换：
```cpp
uint32_t reverseBits(uint32_t n) {
    n = (n >> 16) | (n << 16);
    n = ((n & 0xff00ff00) >> 8) | ((n & 0x00ff00ff) << 8);
    n = ((n & 0xf0f0f0f0) >> 4) | ((n & 0x0f0f0f0f) << 4);
    n = ((n & 0xcccccccc) >> 2) | ((n & 0x33333333) << 2);
    n = ((n & 0xaaaaaaaa) >> 1) | ((n & 0x55555555) << 1);
    return n;
}
```

## P2：工程实践与业务场景

### 3.1 游戏碰撞分层掩码 (LayerMask)

在物理引擎（如 Unity、Unreal）中，物体可能属于玩家、敌军、子弹、地面、触发器等数十个层级：
* 每个物体持有一个 32 位整型 `layer_mask`。
* 判定两物体是否可以发生物理碰撞：
  ```cpp
  bool canCollide(uint32_t maskA, uint32_t maskB) {
      return (maskA & maskB) != 0; // 仅需单条 CPU 位与指令，耗时 < 1ns
  }
  ```

---

### 3.2 角色状态机多重 Buff 标志位管理

MMORPG 中角色可能同时处于“眩晕”、“中毒”、“隐身”、“无敌”、“减速”等多种状态：
* 若每个状态用一个 `bool` 变量，不仅占用数十字节，网络同步还需序列化庞大字段。
* **状态位图**：使用单个 `uint32_t state_flags` 存储所有状态。增加眩晕 `state |= STUN`，解除眩晕 `state &= ~STUN`，网络广播仅需同步单个 4 字节整数。
